# Average Database web

The marketing site is a TanStack Start application deployed to Cloudflare
Workers with the Cloudflare Vite plugin.

## Architecture

`npm run build` prerenders every public page into `dist/client`. Cloudflare
serves those matching assets directly, so ordinary page views do not invoke the
Worker.

The Worker runs first only for:

- `/api/*`, currently used by `/api/gibs-key` as a thin proxy to the existing
  Rust API.
- `/status/incident-report-april-1-2026-control-plane-degradation`, which keeps
  the existing user-agent-dependent April Fools redirect while serving the
  prerendered incident page to link-preview bots.

Unknown navigation requests use the prerendered `404.html`. The Rust API is a
separate deployment and is intentionally unchanged in this migration.

## Commands

```bash
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
npm run check
```

`npm run preview` runs the production output in the local Workers runtime.

## Cloudflare deployment

For a Workers Builds project connected to this repository, use:

- Root directory: `services/web`
- Build command: `npm run build`
- Deploy command: `npx wrangler deploy`

From a local checkout, `npm run deploy` performs both steps. Wrangler
automatically uses the output configuration generated by the Cloudflare Vite
plugin.
